# Convenciones de nombres

- Variables y funciones: `camelCase`.
- Servicios/clases: `PascalCase` (por ejemplo, `TeamService`).
- Constantes: `UPPER_SNAKE_CASE`.
- HTML/CSS: `kebab-case`; archivos `.gs` de servicio: `PascalCase`.
- Código e identificadores en inglés; documentación y texto de interfaz en español.
- Hojas y campos persistidos: `UPPER_SNAKE_CASE` y `snake_case`, respectivamente.
